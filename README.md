# Biblio2026

Scaffold iniziale del progetto web per la biblioteca domestica condivisa.

## Stack

- React + Vite
- TypeScript
- Tailwind CSS
- shadcn/ui (configurazione base)

## Comandi

```bash
npm install
npm run dev
npm run typecheck
npm run lint
npm run build
```

## Struttura

- `src/components`
- `src/pages`
- `src/services`
- `src/hooks`
- `src/utils`
- `src/types`

## Note

- Alias import `@/*` configurato verso `src/*`.
- Base Tailwind + utility `cn` pronta per aggiungere componenti shadcn/ui.
